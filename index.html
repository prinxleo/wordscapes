🚀 Netlify Deployment Guide

1. 10-Second Netlify Drop

Download the ready-made couple_wordscapes_netlify.zip (or save this HTML file as index.html), open app.netlify.com/drop, and drag & drop it. Netlify gives you an instant https://...netlify.app link!

2. Connect Both Phones from Anywhere

Open your Netlify HTTPS link on both phones. Tap Start Cam to allow camera & mic, enter the same Secret Code (e.g. LUV786), and one partner taps Host Room while the other taps Join Partner.

3. Zero-Backend WebRTC P2P

This game uses PeerJS WebRTC Data + Media Streams directly between your two browsers, so your live camera video, audio, and word swipes sync in real time without needing any paid server.
